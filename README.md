# HSE Management System

Professional offline HSE Management System for Windows.

## Main Modules

- Dashboard
- HSE Inspection Register
- Accident / Incident Investigation
- Audit Register
- CAPA Register
- Reports
- Master Data
- Settings

## Reports

- CSV
- Excel
- PDF

## Database

SQLite local database.

Application data is stored in:

%LOCALAPPDATA%\HSE Management System\

## Building

The project is designed to build automatically using GitHub Actions.

No local Python installation is required.

Open:

GitHub
→ Actions
→ Build HSE Management System EXE

Download:

HSE-Management-System-Windows

The artifact contains:

HSE-Management-System.exe
